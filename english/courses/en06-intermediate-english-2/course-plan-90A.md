# EN06 90/A Strategy

## 目標配点

90点を狙うなら、満点を狙うカテゴリと少し落としてよいカテゴリを分ける。

| Category | Weight | Target | Notes |
|---|---:|---:|---|
| Participation | 10 | 9 | 授業中に短くても発言する |
| Homework / Quizzes | 40 | 38 | repeatable/highest score は必ず取り切る |
| Midterm | 20 | 17 | 型暗記 + 例文練習 |
| Final | 30 | 26 | 全Functionの識別と作文 |
| Total | 100 | 90 | Aライン |

## 最重要: Homework / Quizzes 40%

ここが一番取りやすい。Class 1資料によると、Vocabulary / Pronunciation / Dictation は repeatable / highest score の形式がある。つまり、1回で終わらせず、最高点まで繰り返す。

やること:

- Vocabulary: 単語の意味だけでなく、短い例文で覚える。
- Pronunciation: 音読してから提出。発音が怪しい単語を記録する。
- Dictation: 聞こえなかった音をメモする。綴りミスも記録する。
- Unit Written Assignment: 約150 words。Functionの型を必ず使う。

## 授業中の参加点

英語が完璧でなくてもよい。毎回、次のどれかを1回言えれば強い。

- I think ...
- In general, ...
- One reason is because ...
- I predict that ...
- It is possible that ...

## 中間試験

範囲:

- Unit 1: Generalization
- Unit 2: Personal Opinion
- Unit 3: Arguments

対策:

- Functionを見て、どの型か判断する。
- 与えられたtopicに対して、2文で答える練習をする。
- CS例で書けるようにする。

例:

```text
In general, students use online tools to manage assignments.
One reason online tools are useful is because they help students remember deadlines.
```

## 期末試験

範囲:

- Generalization
- Personal Opinion
- Arguments
- Prediction
- Hypothesis
- Synthesis

Synthesis は「複数のFunctionを組み合わせる」問題として考える。

例:

```text
In general, AI tools can help students learn faster.
In my opinion, students should use them carefully.
One reason is because AI can support practice, but it should not replace original thinking.
In the future, universities might create clearer rules for AI use.
```

## Codexの使い方ルール

OK:

- 文法添削
- 自分で書いた文の改善
- 単語テスト作成
- Functionごとの練習問題
- 発音・リスニング練習メニュー作成

NG寄り:

- 提出する英文を丸ごと生成してそのまま出す
- 自分が説明できない表現を使う
- 課題の意図を確認せずに作文を完成させる
