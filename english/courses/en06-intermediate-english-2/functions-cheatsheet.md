# EN06 Function Cheat Sheet

目的: 中間・期末・授業中の発言で、すぐ使える型として覚える。

## 1. Generalization

意味: 一般的な傾向を言う。「普通は」「多くの場合」「一般に」。

### Statement Templates

```text
In general, [subject] [characteristic].
Most [category] are [common characteristic].
Usually, [subject] has/have [feature].
[Category] typically [action/feature].
```

### Question Templates

```text
Do most [subject] [action/feature]?
Is it usual for [subject] to [action/feature]?
```

### CS / University Examples

```text
In general, students use Moodle to check assignments.
Most programming courses require regular practice.
Usually, a server has an address.
Computer systems typically store data in structured formats.
```

## 2. Personal Opinion

意味: 自分の意見を言う。「私はこう思う」。

### Statement Templates

```text
I think [subject] is [opinion].
In my opinion, [subject] is/are [adjective].
I believe that [statement].
I feel [emotion] about [subject].
```

### Question Templates

```text
What is your opinion on [subject]?
Do you believe that [statement]?
```

### CS / University Examples

```text
I think programming is difficult but useful.
In my opinion, English is important for studying computer science.
I believe that daily practice is more effective than cramming.
I feel excited about studying abroad.
```

## 3. Arguments

意味: 理由・根拠をつけて主張する。「なぜなら」「根拠は」。

### Statement Templates

```text
One reason [subject] is/are [opinion] is because [argument].
[Subject] is/are [adjective] because [evidence/supporting detail].
[Example] supports the idea that [statement].
I argue that [statement] due to [reason].
```

### Question Templates

```text
What evidence supports the argument that [argument]?
How would you argue against the claim that [argument]?
```

### CS / University Examples

```text
One reason version control is useful is because it records changes.
Databases are important because they help us manage large datasets.
The success of web services supports the idea that server security is important.
I argue that students should learn English due to its importance in global research.
```

## 4. Prediction

意味: 将来の予測を言う。「今後こうなりそう」。

### Statement Templates

```text
I think [subject] will [future action].
In the future, [subject] might [future possibility].
[Subject] is likely to [future action/condition].
I expect that [future event] will be [adjective].
```

### Question Templates

```text
Based on [subject], what do you predict will happen?
If [condition], what is likely to happen?
```

### CS / University Examples

```text
I think AI tools will become common in education.
In the future, more students might use online learning platforms.
Cybersecurity is likely to become more important.
I expect that the final exam will be challenging but manageable.
```

## 5. Hypothesis

意味: 条件・原因を仮定して考える。「もし〜なら」「原因は〜かもしれない」。

### Statement Templates

```text
If [condition], then [possible result].
Maybe [event] because [possible cause].
It is possible that [event] is caused by [hypothesized reason].
[Event] could be due to [possible factor].
```

### Question Templates

```text
If [event], what do you hypothesize will happen?
Assuming [event], what could be the likely result?
```

### CS / University Examples

```text
If students review vocabulary every day, then their quiz scores will improve.
Maybe the program crashed because the input data was invalid.
It is possible that slow performance is caused by inefficient loops.
The login error could be due to an incorrect password.
```

## One-Minute Speaking Pattern

困ったらこの順番で話す。

```text
In general, ...
In my opinion, ...
One reason is because ...
In the future, ...
```

例:

```text
In general, students use AI tools to study programming.
In my opinion, these tools are useful.
One reason is because they can explain errors quickly.
In the future, students might need to learn how to use AI responsibly.
```
