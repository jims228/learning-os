## 今日やること

- その日のFunctionのテンプレを1つ覚える。
- 授業中に1回、短く発言する。
- 授業後に Moodle の repeatable activities を最高点までやる。

## 5 Functions

| Function | 最短テンプレ |
|---|---|
| Generalization | In general, ... |
| Personal Opinion | I think ... |
| Arguments | One reason is because ... |
| Prediction | I think ... will ... |
| Hypothesis | If ..., then ... |

## すぐ使える発言

```text
I think this topic is important because it is related to computer science.
```

```text
In general, students need practice to improve their English.
```

```text
One reason online tools are useful is because they help students study independently.
```

```text
In the future, AI tools might become common in education.
```

```text
If students use English every day, then their fluency will improve.
```
