# EN06 Intermediate English 2

目的: 2Q の英語を **90点以上 / A** 狙いで進める。

この授業は「英語を知識として覚える」よりも、大学・CS系の場面で使える英語の型を練習する科目。中心は次の5つの academic functions。

1. Generalization
2. Personal Opinion
3. Arguments
4. Prediction
5. Hypothesis

## 毎週の基本ループ

1. 授業前: vocabulary list を覚える。
2. 授業中: 1回は発言する。短くてよい。
3. 授業後: Moodle の quiz / pronunciation / dictation を最高点になるまで繰り返す。
4. 書く課題: 自分で下書きし、文法・表現の修正だけ支援を使う。
5. 週末: その週のFunctionで CS / 大学生活の例文を5個作る。

注意: Class 1資料では、AI Chatbotを使って written assignment を完成させることは不正扱いになり得ると書かれている。Codexは「理解・添削・練習・自分の文の改善」に使う。
