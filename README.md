# learning-os

新後亮人の学習管理リポジトリです。

このリポジトリは、従来の学校課題管理 `SchoolAssignment` と、長期学習管理 `learning-os` を統合したものです。今後は `/home/jimjace/learning-os` を学習の正本として使います。

## 役割

- 学校の試験対策、授業ノート、演習管理
- TOEFL・英語学習の記録と計画
- BCI、宇宙、メタバース・VR、数学など長期テーマの学習管理
- 週次レビュー、月次レポート、日々のメモ管理

## 運用

- 日々の学習メモは `inbox/quick-notes.md` または該当科目のファイルに書く。
- 英語学習は `english/daily-log.md` に記録する。
- 直近の試験対策は `EXAM_PREP_2026-06.md` を起点にする。
- 全体文脈を確認する時は `hub/context-summary.md` を起点にする。
- 長期目標は `hub/goals.md` と `hub/study-plan.md` を起点にする。
- Codex 用の運用指示は `AGENTS.md` を参照する。
