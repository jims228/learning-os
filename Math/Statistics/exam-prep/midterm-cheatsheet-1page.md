## ① 記述統計の式 (問3 系)

```
平均   x̄ = Σxi / n
分散   s² = (Σxi²)/n − x̄²            ← 高速版
        s² = (1/n) Σ(xi − x̄)²       ← 定義版
標準偏差 s = √s²
Q1    下半分の中央値 (n 偶数なら下 n/2 の中央 2 つの平均)
範囲   max − min,   IQR = Q3 − Q1

相関  r = Σ(xi−x̄)(yi−ȳ) / √( Σ(xi−x̄)² · Σ(yi−ȳ)² )
回帰  y = ax + b,  a = r · sy/sx,   b = ȳ − a x̄
R²   = r²
範囲  −1 ≤ r ≤ 1,    0 ≤ R² ≤ 1   ← ★混同注意
```

検算: Σ(xi − x̄) = 0 必ず

## ② 確率 (問6 系)

```
P(A∪B) = P(A) + P(B) − P(A∩B)
P(Aᶜ)  = 1 − P(A)
条件付き P(A|B) = P(A∩B) / P(B)
独立    P(A∩B) = P(A) P(B)
ベイズ   P(A|B) = P(B|A) P(A) / P(B)

1〜N の k の倍数の個数 = ⌊N/k⌋
A かつ B の倍数 = lcm(A,B) の倍数
```

## ③ 期待値・分散 (問7 系)

```
E[aX + bY + c] = a E[X] + b E[Y] + c       ← 常に
V[aX + b]      = a² V[X]                   ← 係数は二乗
独立なら  V[aX + bY] = a² V[X] + b² V[Y]    ← b の二乗忘れ注意

V[X] = E[X²] − (E[X])²
E[X²] = V[X] + (E[X])²

ベルヌーイ Bern(p):  E = p,  V = p(1−p)
二項分布   Bin(n,p): E = np, V = np(1−p)
            P(X=k) = C(n,k) p^k (1−p)^(n−k)
独立なら  P(X=i, Y=j) = P(X=i) P(Y=j)
```

二項係数:
```
C(3,k) = 1, 3, 3, 1
C(5,k) = 1, 5, 10, 10, 5, 1
対称性 C(n,k) = C(n, n−k)
```

## ④ ◯× 問題の罠 (問1, 問5 系)

```
× 因果あり ⇒ 相関高い  (反例: y = x², 因果あり r ≈ 0)
○ 標準化後 a = r, b = 0  (x̄=ȳ=0, sx=sy=1 から導出)
× R² が −1 から 1   (正しくは 0 から 1)
× スピアマン = ±1  ⇒ 単調増加/減少のときのみ
                山型 (例: 1/(0.01+x²)) は単調でないので ±1 にならず

× サンプル数 = n        (正確には「サンプルサイズ」)
× カテゴリ集合 = 標本空間 (正しくはカテゴリ/水準)
○ 標本誤差 = 真値からの有限標本ゆえのずれ
```

## ⑤ 図の読み方 (問2, 問4 系)

ヒストグラム (3 量とも符号は同じ):

```
                   歪度    Q1    平均−中央値
左裾長 (山右)  →    負     負大     負
対称           →    ≈ 0   中間    ≈ 0
右裾長 (山左)  →    正     正/0    正
順序: 左裾 < 対称 < 右裾   (常に同じ向き)
```

裾の方向 = 歪度の符号 (★質量の方向じゃない)

散布図:

```
直線で右上がり    → r → +1, R² → 1
直線で右下がり    → r → −1, R² → 1
ランダム雲        → r ≈ 0, 関係なし
円形・山型 (y=x²) → r ≈ 0 だが関係あり (非線形)
```

R² ≈ 0 の解釈分け:
- 関係あり (円, 山型) → A 系
- 関係なし (ランダム) → B 系
