# 確率統計学 追加レポート用: 写真で確認できる試験問題の解き直し

作成日: 2026-06-12

## 問題1 基礎概念の確認

### (1) 大数の法則・中心極限定理

独立同分布な確率変数列について、

```text
E(X_i) = μ
V(X_i) = σ^2
Xbar_n = (1/n)(X_1 + ... + X_n)
S_n = X_1 + ... + X_n
```

である。

大数の法則は、`n` が大きくなると標本平均 `Xbar_n` が母平均 `μ` に近づくことを説明する。

したがって、

```text
(a) μ
```

和 `S_n` の期待値は、期待値の線形性より、

```text
E(S_n) = E(X_1 + ... + X_n)
       = E(X_1) + ... + E(X_n)
       = nμ
```

したがって、

```text
(b) nμ
```

独立なので、和の分散は分散の和になる。

```text
V(S_n) = V(X_1 + ... + X_n)
       = V(X_1) + ... + V(X_n)
       = nσ^2
```

したがって、

```text
(c) nσ^2
```

中心極限定理より、`n` が大きいとき、和 `S_n` はおおよそ正規分布に従う。

```text
S_n approximately follows N(nμ, nσ^2)
```

したがって、

```text
(d) nμ
(e) nσ^2
```

#### レポート用反省ポイント

ここで間違えやすいのは、標本平均 `Xbar_n` と和 `S_n` を混同することである。大数の法則で近づくのは `Xbar_n` が `μ` に近づくという話である。一方、中心極限定理でここに出ているのは `S_n` なので、平均は `nμ`、分散は `nσ^2` になる。

### (2) 共分散・相関係数・和の分散

与えられている条件は、

```text
V(X) = 4
V(Y) = 9
correlation coefficient = ρ
```

相関係数の定義は、

```text
ρ = Cov(X,Y) / sqrt(V(X)V(Y))
```

なので、

```text
Cov(X,Y) = ρ sqrt(V(X)V(Y))
         = ρ sqrt(4・9)
         = 6ρ
```

したがって、

```text
(f) 6ρ
```

和の分散は、

```text
V(X+Y) = V(X) + V(Y) + 2Cov(X,Y)
       = 4 + 9 + 2・6ρ
       = 13 + 12ρ
```

したがって、

```text
(g) 13 + 12ρ
```

`-1 <= ρ <= 1` なので、`13 + 12ρ` が最小になるのは `ρ = -1` のとき。

```text
13 + 12(-1) = 1
```

したがって、

```text
(h) -1
(i) 1
```

#### レポート用反省ポイント

ここでは、相関係数 `ρ` と共分散 `Cov(X,Y)` は同じものではない。相関係数は、共分散を標準偏差で割って -1 から 1 の範囲に直したものである。したがって、まず `Cov(X,Y) = ρ sqrt(V(X)V(Y))` に戻す必要がある。

### (3) 95%信頼区間の解釈

正しい解釈は、

```text
(2) 同じ方法で標本抽出と区間計算を何度も繰り返すと、
    そのうち約95%の区間が母平均を含む。
```

したがって、

```text
(j) 2
```

#### レポート用反省ポイント

一度計算された区間について、「母平均が95%の確率で入っている」とは言わない。母平均は固定された値であり、ランダムなのは標本から作る信頼区間の方である。

### (4) p値の説明

正しい説明は、

```text
(3) 帰無仮説のもとで、今回の結果またはそれ以上に極端な結果が出る確率。
```

したがって、

```text
(k) 3
```

#### レポート用反省ポイント

p値は「帰無仮説が正しい確率」ではない。帰無仮説が正しいと仮定したときに、今回のような極端なデータがどれくらい起こりにくいかを見る値である。

## 問題2 条件付き確率とベイズの定理

事象を次のようにおく。

```text
D = 実際に不正アクセスが起こっている
A = 警告が出る
```

与えられている条件は、

```text
P(D) = 0.01
P(D^c) = 0.99
P(A|D) = 0.9
P(A^c|D^c) = 0.9
```

したがって、

```text
P(A|D^c) = 1 - P(A^c|D^c)
          = 1 - 0.9
          = 0.1
```

### (1)

不正アクセスでないのに警告が出る確率は、

```text
P(A|D^c) = 0.1
```

したがって、

```text
(a) 0.1
```

### (2)

ランダムに1件選んだとき警告が出る確率は、全確率の公式より、

```text
P(A) = P(A|D)P(D) + P(A|D^c)P(D^c)
     = 0.9・0.01 + 0.1・0.99
     = 0.009 + 0.099
     = 0.108
```

したがって、

```text
(b) 0.108
```

### (3)

警告が出たアクセスのうち、実際に不正アクセスである確率は、

```text
P(D|A) = P(A|D)P(D) / P(A)
       = 0.9・0.01 / 0.108
       = 0.009 / 0.108
       = 1/12
       ≈ 0.0833
```

したがって、

```text
(c) 0.0833
```

### (4)

改良後は、

```text
P(A^c|D^c) = 0.95
```

なので、

```text
P(A|D^c) = 1 - 0.95
          = 0.05
```

このとき、

```text
P(A) = P(A|D)P(D) + P(A|D^c)P(D^c)
     = 0.9・0.01 + 0.05・0.99
     = 0.009 + 0.0495
     = 0.0585
```

したがって、

```text
P(D|A) = P(A|D)P(D) / P(A)
       = 0.009 / 0.0585
       ≈ 0.1538
```

```text
(d) 0.1538
```

### (5)

目標は、

```text
P(D|A) ≈ 0.093
```

である。`q = P(A^c|D^c)` とおくと、

```text
P(A|D^c) = 1 - q
```

だから、

```text
0.093 ≈ 0.009 / {0.009 + (1-q)・0.99}
```

これを解くと、

```text
q ≈ 0.911
```

選択肢で最も近いのは、

```text
(2) 0.912
```

したがって、

```text
(e) 2
```

#### レポート用反省ポイント

この問題では、`P(A|D)` と `P(D|A)` を混同すると大きく間違える。`P(A|D)` は「不正アクセスだったとき警告が出る確率」であり、`P(D|A)` は「警告が出たとき本当に不正アクセスである確率」である。ベイズの定理では、分母に `P(A)` を作る必要がある。

## 問題3 確率変数の和と中心極限定理

確率変数 `X` は、

```text
P(X=0) = 1/4
P(X=1) = 1/2
P(X=2) = 1/4
```

を満たす。

### (1)

期待値は、

```text
E(X) = 0・1/4 + 1・1/2 + 2・1/4
     = 0 + 1/2 + 1/2
     = 1
```

したがって、

```text
(a) 1
```

### (2)

まず、

```text
E(X^2) = 0^2・1/4 + 1^2・1/2 + 2^2・1/4
       = 0 + 1/2 + 1
       = 3/2
```

したがって、

```text
(b) 3/2
```

分散は、

```text
V(X) = E(X^2) - {E(X)}^2
     = 3/2 - 1^2
     = 1/2
```

したがって、

```text
(c) 1/2
```

### (3)

`S_32 = X_1 + ... + X_32` であり、独立同分布なので、

```text
E(S_32) = 32 E(X)
        = 32
```

```text
V(S_32) = 32 V(X)
        = 32・1/2
        = 16
```

したがって、

```text
(d) 32
(e) 16
```

### (4)

中心極限定理より、

```text
S_32 approximately follows N(32, 16)
```

標準偏差は、

```text
sqrt(16) = 4
```

なので、

```text
P(28 <= S_32 <= 36)
```

を標準化すると、

```text
P((28-32)/4 <= Z <= (36-32)/4)
= P(-1 <= Z <= 1)
```

標準正規分布表より、

```text
P(-1 <= Z <= 1) = 0.8413 - 0.1587
                = 0.6826
```

したがって、

```text
(f) 約 0.683
```

#### レポート用反省ポイント

この問題では、`E(X^2)` から分散を出すときに、`V(X) = E(X^2) - {E(X)}^2` を使う必要がある。また、`S_32` は32個の和なので、平均も分散も32倍になる。標本平均ではないので、分散を32で割らない。

## 問題4 正規分布・信頼区間・検定

### (1)

得点 `X` は、

```text
X follows N(60, 15^2)
```

である。

```text
P(X >= 90)
= P((X-60)/15 >= (90-60)/15)
= P((X-60)/15 >= 2)
```

したがって、

```text
(a) 2
```

ここで、

```text
Z = (X-60)/15
```

とおくと、`Z` は標準正規分布に従う。

```text
(b) 標準正規分布 N(0,1)
```

したがって、

```text
P(X >= 90) = P(Z >= 2)
```

```text
(c) 2
```

標準正規分布表より、

```text
P(Z >= 2) = 1 - P(Z <= 2)
          = 1 - 0.9772
          = 0.0228
```

したがって、

```text
(d) 0.0228
```

### (2)

16人のデータについて、

```text
n = 16
xbar = 74
s = 8
```

母分散が未知で、標本標準偏差 `s` を使っているので、t分布を使う。

98%信頼区間なので、

```text
α = 0.02
α/2 = 0.01
```

自由度は、

```text
n - 1 = 15
```

t分布表より、

```text
t_0.01(15) ≈ 2.602
```

標準誤差は、

```text
s / sqrt(n) = 8 / sqrt(16) = 8/4 = 2
```

したがって、98%信頼区間は、

```text
xbar ± t_0.01(15)・s/sqrt(n)
= 74 ± 2.602・2
= 74 ± 5.204
```

よって、

```text
(e) (68.8, 79.2)
```

### (3)

「教材導入後の母平均は70点より高い」といえるかを調べるので、

```text
H_0: μ = 70
H_1: μ > 70
```

したがって、

```text
(f) 70
(g) 70
```

検定統計量は、

```text
T = (xbar - 70) / (s/sqrt(16))
  = (74 - 70) / (8/4)
  = 4 / 2
  = 2
```

したがって、

```text
(h) 2
```

自由度15のt分布表より、

```text
t_0.05(15) ≈ 1.753
t_0.025(15) ≈ 2.131
```

したがって、

```text
(i) 1.753
(j) 2.131
```

5%水準では、

```text
T = 2 > 1.753
```

なので、帰無仮説を棄却する。

```text
(k) 棄却する
```

2.5%水準では、

```text
T = 2 < 2.131
```

なので、帰無仮説を棄却しない。

```text
(l) 棄却しない
```

#### レポート用反省ポイント

この問題では、母分散が既知ではなく、標本標準偏差 `s` が与えられているので、標準正規分布ではなく t 分布を使う。また、信頼区間では両側なので `α/2` を使い、検定では片側検定なので `t_0.05(15)` や `t_0.025(15)` と比較する。
