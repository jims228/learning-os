### 正しくはどう考えるべきか

```text
E[ Xbar ] = μ
```

## 問2 条件付き確率・ベイズの定理

### 試験中の考え

条件付き確率またはベイズの定理の問題では、私は `P(A|B)` と `P(B|A)` の違いを十分に意識せず、問題文に出てきた数字をそのまま掛けたり割ったりした可能性がある。

試験中は「Aが起こったときB」なのか「Bが分かったあとAを知りたい」のかを整理する前に式を書いてしまった。

### 何が不十分だったか

条件付き確率では、分母は「条件としてすでに分かっている世界」である。

```text
P(A|B) = P(A∩B) / P(B)
```

ここで `B` が条件なら、分母は必ず `P(B)` でなければならない。

ベイズの定理では、知りたい確率が

```text
P(A|B)
```

であっても、問題文では

```text
P(B|A)
```

や

```text
P(B|A^c)
```

が与えられることが多い。そのため、分母 `P(B)` を全確率の公式で作る必要がある。

```text
P(B) = P(B|A)P(A) + P(B|A^c)P(A^c)
```

### 正しくはどう考えるべきか

ベイズ型の問題では、次の順番で解くべきだった。

1. 知りたい事象を `A` と置く。
2. 観測された条件を `B` と置く。
3. 求めたいものが `P(A|B)` であることを確認する。
4. 分子 `P(B|A)P(A)` を作る。
5. 分母 `P(B)` を全確率の公式で作る。

式としては、

```text
P(A|B)
= P(B|A)P(A) / { P(B|A)P(A) + P(B|A^c)P(A^c) }
```

である。

私の誤りは、条件付き確率を「ただの割合」と見て、条件によって見ている標本空間が変わることを十分に意識していなかった点にある。

## 問3 中心極限定理の応用

### 試験中の考え

中心極限定理の問題では、私は「標本サイズが大きいと正規分布になる」という言葉だけを覚えており、何が正規分布に近づくのかを明確にできていなかった。

そのため、元のデータそのものが正規分布になるように考えたり、標本平均の分散を `σ^2` のまま扱った可能性がある。

### 何が不十分だったか

中心極限定理が言っているのは、元のデータ `X` が正規分布に近づくということではない。

独立同分布な確率変数 `X1, X2, ..., Xn` について、

```text
E[Xi] = μ
Var(Xi) = σ^2
```

であれば、標本平均

```text
Xbar = (X1 + ... + Xn) / n
```

について、

```text
E[Xbar] = μ
Var(Xbar) = σ^2 / n
```

となる。

そして、標準化した標本平均

```text
Z = (Xbar - μ) / (σ / sqrt(n))
```

が標準正規分布 `N(0,1)` に近づく。

### 正しくはどう考えるべきか

中心極限定理の問題では、次の形を作る必要がある。

```text
Xbar ≈ N( μ, σ^2/n )
```

または標準化して、

```text
Z = (Xbar - μ) / (σ/sqrt(n)) ≈ N(0,1)
```

たとえば、平均が `50`、分散が `4` の母集団から `n=100` の標本を取るなら、

```text
Xbar ≈ N(50, 4/100)
```

である。

ここで `4/100` になる理由は、個々のデータの分散が `4` でも、100個の平均を取ることで標本平均の分散は `1/100` 倍になるからである。

試験中の私は、標準偏差・分散・標準誤差の関係を十分に区別できていなかった。正しくは、標本平均を扱うときは必ず `σ/sqrt(n)` を使う。

## 問4 推定・信頼区間・仮説検定

### 試験中の考え

推定や仮説検定の問題では、私は公式の形を覚えていても、母分散が既知か未知か、z分布を使うのかt分布を使うのか、仮説検定なのか信頼区間なのかの判断が遅れた。

また、信頼区間の解釈やp値の意味を、言葉として正確に書けなかった可能性がある。

### 何が不十分だったか

信頼区間では、最初に次を確認する必要がある。

1. 求める母数は平均か比率か。
2. 母分散は既知か未知か。
3. 標本サイズはいくつか。
4. 信頼区間か検定か。

母分散が既知なら、

```text
Xbar ± z_(α/2) σ/sqrt(n)
```

を使う。

母分散が未知なら、標本標準偏差 `s` を使い、

```text
Xbar ± t_(α/2, n-1) s/sqrt(n)
```

を使う。

私が不十分だったのは、「標本標準偏差が与えられているから、そのままσとしてzを使えばよい」と考えてしまう点である。母分散が未知で標本標準偏差を使う場合は、原則としてt分布を使う。

### 正しくはどう考えるべきか

たとえば、標本平均が `xbar`、標本標準偏差が `s`、標本サイズが `n` で母平均の95%信頼区間を求める問題では、

```text
xbar ± t_(0.025, n-1) s/sqrt(n)
```

とする。

仮説検定では、まず仮説を立てる。

```text
H0: μ = μ0
H1: μ ≠ μ0
```

母分散未知なら、検定統計量は

```text
t = (xbar - μ0) / (s/sqrt(n))
```

である。

この値をt分布の棄却域と比べるか、p値で判断する。

p値は「帰無仮説が正しい確率」ではない。正しくは、

```text
帰無仮説が正しいと仮定したとき、
今回の結果と同じか、それ以上に極端な結果が出る確率
```

である。

また、95%信頼区間は「この区間に95%の確率で母平均が入る」という意味ではない。正しくは、

```text
同じ手順で標本抽出と区間作成を何度も繰り返したとき、
そのうち約95%の区間が真の母平均を含む
```

という意味である。
