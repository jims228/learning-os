# 心理言語学 Course Info

作成: 2026-06-08  
位置づけ: 2Qの履修検討・BCI/留学接続メモ

## この授業の概要

心理言語学は、人間がどうやって言語を理解し、処理し、産出するかを調べる分野。

普通の言語学が「言語のルール」を見るのに対して、心理言語学は「人間の頭の中で、その言語処理がどう起きているか」を見る。

この授業では、講義と実習を組み合わせて進む。

- 心理言語学の理論
- 実験デザイン
- PCIbexによるオンライン実験
- JavaScriptで刺激文を変更する練習
- Rによる統計分析
- 眼球運動測定
- ERP / 脳電位測定
- 期末口頭発表

## 心理言語学を一言で言うと

```text
人間が言葉を読んだり聞いたりするとき、脳と心の中で何が起きているかを、実験で調べる学問。
```

例:

- 人は文を読むとき、どこでつまずくのか。
- 曖昧な文を読んだとき、どの解釈を先に選ぶのか。
- 単語の意味はどのくらい速く処理されるのか。
- 文法的に変な文を読むと、脳波にどんな反応が出るのか。
- 視線の動きから、理解の難しさは読めるのか。

## BCIとの関係

この授業はBCIそのものの授業ではない。

ただし、BCIに入る前の足場としてかなり関係がある。

| 授業内容 | BCIとの接続 |
|---|---|
| 実験デザイン | 人を対象にした研究計画に必要 |
| PCIbex | 刺激提示・反応取得の基礎 |
| JavaScript | 実験のカスタマイズに使える |
| R | 実験データ分析に必要 |
| 眼球運動測定 | HCI / XR / 注意推定 / 入力インターフェースに近い |
| ERP / 脳電位 | EEG系BCIの入口 |
| 英語発表 | 留学・研究室面談に効く |

## PCIbexとは

PCIbexは、ブラウザ上で心理言語学や認知科学の実験を作るためのツール。

できること:

- 文章や画像などの刺激を出す。
- 参加者にキー入力やクリックで反応してもらう。
- 反応時間を取る。
- 条件ごとに刺激を変える。
- オンライン実験として配布する。
- 結果データを保存して分析に回す。

ざっくり言うと、

```text
心理実験用のWebアプリを、JavaScriptで比較的簡単に作るための環境。
```

## 履修判断

取る価値はある。

理由:

- 英語授業に慣れる訓練になる。
- BCIで必要な実験設計・データ分析・脳波/視線計測に触れられる。
- JavaScriptとRを使うのでCS学生としても無駄になりにくい。
- 期末試験ではなく発表型なので、早めにテーマを決めれば戦いやすい。

注意:

- 授業外240分想定なので軽くはない。
- 発表40%なので、最後に逃げると危ない。
- 英語資料を読む必要がある。

## 亮人さん向けのおすすめテーマ

もし発表テーマを選べるなら、次の方向へ寄せる。

1. P300 speller and language-based BCI
2. ERP responses to syntactic or semantic violations
3. Eye-tracking as an input or attention signal
4. Reaction time experiments for language understanding
5. Adaptive story systems using user responses
