# 創業者学習ロードマップ 2026

作成日: 2026-06-14  
位置づけ: 事業・留学・米国大学院・将来の産業挑戦に必要な学習を、日々の勉強に落とすための地図。  
関連repo: `/home/jimjace/jims-company-os`

## 0. 結論

学習の目的は、単位を取ることだけではない。

```text
会津で勝つ。会津に閉じない。外で戦える会社にする。
```

そのために、今の勉強は次の4つへ接続する。

1. Jims Worksを伸ばす。
2. 雪包装・山本商事・次の顧客に責任を持つ。
3. 米国大学院・海外人材・研究者と戦える基礎を作る。
4. 将来、農業・電力・ロボティクス・宇宙・BCIのような未来のインフラ領域へ進む。

業務AIは最終目的地ではない。ただし、今は業務AIで売上・信用・顧客・現場データ・仲間を作る段階。勉強もこの順番に合わせる。

## 1. 優先順位

### Sランク: 毎週必ずやる

| 分野 | 理由 | 2026年の使い道 |
|---|---|---|
| 英語 | 留学、米国大学院、海外人材、論文、投資家、技術情報の入口 | TOEFL、海外記事、論文、英語発信 |
| 統計・確率・線形代数 | AI、評価、衛星データ、機械学習、意思決定の基礎 | OCR精度評価、マッチング精度、実証結果分析 |
| CS基礎 | 技術判断、実装品質、チームへの指示に必要 | DB、API、セキュリティ、アルゴリズム |
| 会計・ファイナンス | 会社を壊さないための基礎 | 資金繰り、粗利、価格、法人化、融資 |
| 営業・交渉・文章 | 売上、人材、投資、顧客信頼に直結 | 商談、提案書、メール、採用、紹介依頼 |

### Aランク: 事業に合わせて積む

| 分野 | 理由 | 2026年の使い道 |
|---|---|---|
| AI/ML実装 | Jims Worksの中核 | OCR、RAG、LLM評価、エージェント、マスタ照合 |
| セキュリティ・バックアップ | 顧客データを預かる会社の必須品質 | RLS、権限、監査ログ、復旧手順 |
| 契約・法務・知財 | 法人化、NDA、業務委託、成果物帰属に必要 | 契約書、補助金、保守契約、共同開発 |
| プロダクトマネジメント | 何を作り、何を捨てるかの判断 | 雪包装改善、山本商事資料、アオタケ実証 |

### Bランク: 長期探索

| 分野 | 理由 | 2026年の扱い |
|---|---|---|
| 農業・食料 | アオタケ、会津坂下、現場AIに接続 | ヒアリング、作業カード、農業DX調査 |
| 電力・エネルギー | AI、ロボット、農業、宇宙の土台 | 設備/保守/電材卸から学ぶ |
| ロボティクス・Physical AI | 現場作業の未来 | 農業/物流/工場の文脈で調査 |
| 宇宙・衛星データ | 長期の未来インフラ | 衛星データ、通信、宇宙電力を学ぶ |
| BCI・神経科学 | 長期北極星 | 信号処理、HCI、アクセシビリティから入る |
| エンタメ・ゲーム | 人を動かす表現、ブランド | 小さく作り続ける。事業本丸を壊さない |

## 2. 毎日の最低ライン

忙しい日でも、最低これだけはやる。

1. 英語 15分
   - TOEFL、英語記事、技術記事、海外創業者インタビューのどれか。
2. 数学/統計/CS 30分
   - 授業、再履修対策、演習、アルゴリズム、DBのどれか。
3. 事業に近い学習 15分
   - 会計、営業、契約、セキュリティ、AI評価、顧客業界調査のどれか。

合計60分。  
時間がない日は60分でよい。余裕がある日は2〜3時間へ伸ばす。

## 6. インターン・就活の扱い

普通の就活は、今は優先しない。

今やらなくてよい:

- なんとなくの就活サイト登録。
- 周りがやっているから行く会社説明会。
- 事業と関係ないサマーインターン大量応募。

検討してよい:

- AI、ロボティクス、宇宙、農業、電力、BCIに直結するインターン。
- 海外大学院や研究室推薦に効く研究接点。
- 優秀な人材、研究者、起業家と会える機会。
- Jimsの3年後を強くする経験。

判断基準:

```text
そのインターンは、Jimsの3年後を強くするか。
```

強くしないなら、今は不要。

## 7. 方向を間違えないためのチェック

毎週、自分に聞く。

1. 今週、売上に近づいたか。
2. 雪包装・山本商事・次の顧客への責任を果たしたか。
3. 英語、統計、CSのどれかを積んだか。
4. 会津に閉じないための準備をしたか。
5. 勉強管理だけで満足していないか。

勉強の目的は、ノートを増やすことではない。  
外の世界で勝負できる創業者になること。
