# 2026 2Q 学習計画

作成: 2026-06-08  
更新: 2026-06-11（履修整理）
期間: 2026-06-10頃から2Q終了まで

## 方針

1Q後半は試験前に一気に詰め込む形になった。
2Qは、毎週のQuiz / Exercise / Assignmentを落とさない運用に切り替える。

確率統計論は単位取得に失敗したため、再履修前提で立て直す。2Qの主目的は「毎週の授業運用を崩さないこと」。

2Qで通常運用する授業:

- FU03 離散系論
- FU15 データマネジメント概論

履修から外した授業:

- 熱・統計力学
- 心理言語学

これらの資料はrepo内に残すが、2Qの締切管理・通常学習からは外す。

## 2Qの優先順位

| 優先 | 項目 | 理由 |
|---:|---|---|
| 1 | 授業の締切管理 | 単位を安全に取る |
| 2 | FU15 / FU03 の毎週運用 | Quiz・Exercise・Assignmentを落とさない |
| 3 | TOEFL / 英語 | 来年留学の土台 |
| 4 | 確率統計論の再履修準備 | 同じ失敗を繰り返さない |
| 5 | BCI接点 | 研究室・テーマ選びの準備 |

## 科目別

### FU03 離散系論

入口:

- `DiscreteSystems/FU03/course-info.md`
- `DiscreteSystems/FU03/quick-start.md`

重要:

- Assignments 30%、Final exam 70%。
- Lesson 01は集合・命題論理・数学的帰納法。
- 英語用語と証明テンプレートを早めに固める。

### FU15 データマネジメント概論

入口:

- `DataManagement/FU15/course-info.md`
- `DataManagement/FU15/quick-start.md`

重要:

- Quizは1回のみ、10-20分制限。
- 通常、次の講義前日の23:55まで。
- Exerciseはzip提出。
- ER図、metadata、data modelingを早めに固める。

### 心理言語学

履修から外したため、2Qの通常タスクから除外。

資料:

- `Psycholinguistics/course-info.md`

扱い:

- BCI・認知科学の将来候補としてメモは残す。
- 今期の締切管理には入れない。

### 熱・統計力学

履修から外したため、2Qの通常タスクから除外。

資料:

- `Physics/ThermoStatMech/course-info.md`
- `Physics/ThermoStatMech/quick-start.md`

扱い:

- 物理・統計力学の将来候補として資料は残す。
- 今期の締切管理には入れない。

### 確率統計論 再履修準備

状態:

- 2026年6月の確率統計論は単位取得に失敗。
- 追試はなさそうなので、再履修前提で扱う。

2Qでやること:

- 普段の授業を優先し、確率統計論は週1回だけ基礎を維持する。
- まずは「記述統計・確率・期待値・分散」まで戻る。
- AIに丸投げせず、自分で紙に式を書く時間を必ず入れる。

## 毎週レビュー

毎週末に次を確認する。

| 確認 | 内容 |
|---|---|
| 締切 | Quiz / Exercise / Assignmentを全部出したか |
| 英語 | TOEFLまたは授業英語に触れたか |
| BCI | 研究室・論文・実験系の接点が1つ増えたか |
| 危険科目 | 置いていかれている科目はあるか |
| 自立 | AIの解説を読んだだけで終わらず、自分で解いたか |

## 平日ミニルーティン

忙しい日の最低ライン。

| 時間 | 内容 |
|---:|---|
| 20分 | その日の授業資料を軽く読む |
| 20分 | Quiz / Exercise / Assignmentの期限確認 |
| 20分 | 英語または専門用語の復習 |

余裕がある日は、TOEFL / BCI / 確率統計論の基礎復習を追加する。

## AIとの付き合い方

目的は、AIに解かせることではなく、AIを使って自分が解ける状態にすること。

毎回の勉強は次の形にする。

1. まず自分で5分読む。
2. 分からない語・式・課題文をAIに説明させる。
3. AIの解説を見ずに、自分で1問解く。
4. 自分の解答をAIに採点させる。
5. 最後に「今日自分でできるようになったこと」を1行で残す。

## Codex運用

授業資料が出たら、次の順で整理する。

1. `course-info.md` に評価・期限・範囲を追記。
2. 講義ごとに `lectures/` へ要点を作る。
3. 課題は `exercises/` へ保存。
4. 試験や発表が見えたら `exam-prep/` または `presentation-prep/` を作る。

試験直前まで溜めない。
