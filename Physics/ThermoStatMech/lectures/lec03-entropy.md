## 1. エントロピーの定義

エントロピー `S` は、物体の状態だけで決まる量。

可逆変化で状態Aから状態Cへ移るとき、

```text
S(C) - S(A) = ∫_A^C δQ / T
```

微小変化では、

```text
dS = δQ / T
```

ただし、これは可逆変化で考える。

第一法則の

```text
δQ = dU + p dV
```

と合わせると、

```text
dS = (dU + p dV) / T
```

## 2. 熱は状態量ではないが、エントロピーは状態量

カルノーサイクルを1周すると、状態は元に戻る。

そのため、

```text
∮ dS = 0
```

一方、熱については、

```text
∮ δQ = Q2 - Q1 ≠ 0
```

となる。

つまり、

```text
熱 Q は状態量ではない。
エントロピー S は状態量である。
```

## 3. カルノーサイクルとの関係

カルノーサイクルでは、

```text
Q1 / Q2 = T1 / T2
```

したがって、

```text
Q1 / T1 = Q2 / T2
```

この形が、エントロピー `δQ/T` の考え方につながる。

## 4. エントロピー増大の法則

温度の異なる2つの系を接触させる。

```text
低温側: T1
高温側: T2
T1 < T2
```

熱は自然に高温側から低温側へ流れる。

高温側から低温側へ熱量 `ΔQ` が移動すると、

```text
低温側のエントロピー変化:  ΔQ / T1
高温側のエントロピー変化: -ΔQ / T2
```

全体では、

```text
ΔS = ΔQ / T1 - ΔQ / T2
    = ΔQ(1/T1 - 1/T2)
```

`T1 < T2` なので、

```text
1/T1 > 1/T2
```

よって、

```text
ΔS > 0
```

つまり、

```text
自然に起こる変化では、全体のエントロピーは増大する。
```

## 5. 不可逆変化の場合

不可逆変化では、実際の経路に沿ってそのまま `δQ/T` を積分してエントロピー変化を出すことはできない。

状態Aから状態Bへのエントロピー変化は、同じ始点と終点を結ぶ可逆経路を考えて計算する。

断熱不可逆変化では、`Q = 0` でも、

```text
S(B) - S(A) > 0
```

となる。

ここが大事:

```text
断熱だからエントロピー変化0、とは限らない。
可逆断熱なら0。
不可逆断熱なら増える。
```

## 6. 理想気体のエントロピー

1 mol の理想気体では、

```text
U = Cv T
dU = Cv dT
```

また、

```text
pV = RT
```

なので、

```text
dS = (dU + p dV) / T
```

に代入すると、

```text
dS = Cv dT/T + R dV/V
```

積分して、

```text
S(T,V) = Cv ln T + R ln V + const
```

また、`γ = 1 + R/Cv` とおくと、

```text
S(T,V) = Cv ln(T V^(γ-1)) + const
```

という形でも書ける。

## 7. Lec03で最低限覚える式

```text
dS = δQ_rev / T
S(B) - S(A) = ∫_A^B δQ_rev / T
ΔS = ΔQ(1/T1 - 1/T2)
dS = Cv dT/T + R dV/V
S(T,V) = Cv ln T + R ln V + const
```

## 8. 試験・演習で大事な考え方

- エントロピーは状態量。
- 熱は状態量ではない。
- 可逆変化なら `dS = δQ/T`。
- 不可逆変化では、同じ始点・終点を結ぶ可逆経路で計算する。
- 自然に起こる変化では、孤立系全体のエントロピーは増大する。
- 理想気体の自由膨張では温度は変わらないが、エントロピーは増える。
