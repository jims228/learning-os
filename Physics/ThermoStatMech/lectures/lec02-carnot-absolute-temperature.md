## 前回の復習

前回の中心は第一法則と仕事。

```text
dU = δQ + δW
δW = -p dV
δQ = dU + p dV
```

この授業の符号では、`δW` は「外部から気体にされた仕事」。

## 熱効率

熱機関は、高温熱源から熱を受け取り、その一部を仕事として取り出し、残りを低温熱源へ捨てる。

```text
高温熱源から得た熱量: Q2
低温熱源へ捨てた熱量: Q1
外界にした仕事: -W
```

熱効率は、

```text
η = 外界にした仕事 / 高温熱源から得た熱量
```

この授業の記号では、

```text
η = (-W) / Q2
```

エネルギー保存より、

```text
-W = Q2 - Q1
```

なので、

```text
η = (Q2 - Q1) / Q2
  = 1 - Q1 / Q2
```

## カルノーサイクル

カルノーサイクルは、一番有名な熱機関の理想モデル。

資料では、2つの熱源を考える。

```text
高温熱源: T2
低温熱源: T1
```

4つの過程:

| 過程 | 内容 |
|---|---|
| A -> B | 高温 T2 での等温過程 |
| B -> C | 断熱過程 |
| C -> D | 低温 T1 での等温過程 |
| D -> A | 断熱過程 |

1周したとき、内部エネルギーは元に戻るので、

```text
ΔU = 0
```

したがって、1周で外へ取り出せる仕事は、受け取った熱と捨てた熱の差になる。

```text
-W = Q2 - Q1
```

## カルノー効率

カルノーサイクルの熱効率は、

```text
ηc = 1 - T1 / T2
```

ここで温度は必ず絶対温度 K を使う。

```text
T[K] = t[℃] + 273
```

例:

```text
高温熱源 800℃
低温熱源 20℃
```

```text
T2 = 800 + 273 = 1073 K
T1 = 20 + 273 = 293 K
```

```text
ηc = 1 - 293 / 1073
    ≒ 0.727
```

小数第3位を四捨五入すると、

```text
ηc ≒ 0.73
```

## 絶対温度

カルノーの定理により、2つの決まった熱源の間ではたらく可逆熱機関の熱効率は、作業物質の種類によらず、両熱源の温度だけで決まる。

そのため、物質に依らない温度目盛りとして絶対温度を導入できる。

単位:

```text
K
```

## 準静的過程と可逆過程

準静的過程:

```text
きわめてゆっくり変化が起こり、どの瞬間でも熱平衡が実現している過程
```

可逆過程:

```text
ちょうど逆向きの変化を起こして、もとと全く同じ状態に戻せるような変化
```

重要:

```text
可逆な過程は、準静的過程でなければならない。
```

さらに、可逆過程では散逸が起こってはいけない。

## ヒートポンプ

ヒートポンプは、熱機関の逆回転のようなもの。

例:

- エアコン
- 冷蔵庫
- 冷凍庫

熱機関:

```text
高温側から低温側へ熱が移動し、その一部を仕事として取り出す。
```

ヒートポンプ:

```text
外部から仕事を与えて、低温側から高温側へ熱を移動する。
```

ヒートポンプの効率は、成績係数 COP で表す。

```text
COP = 移動させた熱量 / 外部から与えた仕事
```

COPは高いほど省エネ。

## Lec02で最低限覚える式

```text
η = (-W) / Q2
-W = Q2 - Q1
η = 1 - Q1 / Q2
ηc = 1 - T1 / T2
T[K] = t[℃] + 273
```

## 試験・宿題で使えそうなポイント

- 熱効率は「もらった熱のうち、どれだけ仕事に変えられたか」。
- カルノーサイクルは、等温2つ・断熱2つからなる理想的な可逆サイクル。
- カルノー効率は温度だけで決まる。
- 温度は℃ではなくKに直してから使う。
- ヒートポンプは熱機関の逆向き。
