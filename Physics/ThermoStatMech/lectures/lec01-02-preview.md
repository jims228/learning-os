## 1. 熱力学は何を見る学問か

熱力学は、物体を分子1個1個ではなく、全体として見る。

たとえば気体なら、

- 温度 T
- 圧力 p
- 体積 V
- 内部エネルギー U

のような量で状態を表す。

## 2. 熱力学第一法則

一番大事な式。

```text
dU = δQ + δW
```

意味:

```text
内部エネルギーの変化 = 外から入った熱 + 外からされた仕事
```

ここで注意:

- U は状態量
- Q と W は過程に依存する量

そのため、資料では次のように書き分ける。

```text
dU
δQ
δW
```

`dU` は状態量の微小変化。  
`δQ`, `δW` は「経路に依存する微小な熱・仕事」。

## 3. 気体のする仕事

準静的な体積変化では、仕事は次の形で出る。

```text
δW = -p dV
```

この授業の符号では、`δW` は「外部から気体にされた仕事」。

だから、

| 場合 | dV | δW = -p dV | 意味 |
|---|---:|---:|---|
| 膨張 | 正 | 負 | 気体が外へ仕事をする |
| 圧縮 | 負 | 正 | 外部が気体へ仕事をする |

第一法則に入れると、

```text
dU = δQ - p dV
```

または、

```text
δQ = dU + p dV
```

## 4. 熱容量の式につながるところ

内部エネルギーを温度Tと体積Vの関数と見ると、

```text
U = U(T, V)
```

なので、

```text
dU = (∂U/∂T)_V dT + (∂U/∂V)_T dV
```

これを

```text
δQ = dU + p dV
```

に入れると、

```text
δQ
= (∂U/∂T)_V dT + {p + (∂U/∂V)_T} dV
```

このあたりから、定積熱容量・定圧熱容量の話につながる。

## 5. 熱力学第二法則の入口

第二法則は、ざっくり言うと「熱には自然な流れの向きがある」という法則。

直感:

```text
熱いものから冷たいものへ熱は自然に流れる。
冷たいものから熱いものへ、勝手には流れない。
```

この「向き」が、あとでエントロピーにつながる。

## 6. 熱機関と熱効率

熱機関は、高温熱源から熱を受け取り、その一部を仕事に変える装置。

典型的なイメージ:

```text
高温熱源 T2 から Q2 を受け取る
↓
一部を仕事 -W として取り出す
↓
残り Q1 を低温熱源 T1 へ捨てる
```

熱効率:

```text
η = 取り出した仕事 / 受け取った熱
```

資料の符号では、

```text
η = -W / Q2
```

また、エネルギー保存から、

```text
-W = Q2 - Q1
```

なので、

```text
η = (Q2 - Q1) / Q2
  = 1 - Q1/Q2
```

## 7. カルノー効率

カルノーサイクルは、理想的な熱機関。

最大効率は、

```text
ηc = 1 - T1/T2
```

ここで、

- T2 は高温熱源の絶対温度
- T1 は低温熱源の絶対温度
- 温度はセルシウスではなくKで使う

例:

```text
T2 = 800℃ = 273 + 800 = 1073 K
T1 = 20℃  = 273 + 20  = 293 K
```

```text
ηc = 1 - 293/1073
   ≒ 0.73
```

つまり、理想的でも73%くらいが上限。

## 8. 予習で覚える最低限

```text
熱力学第一法則:
dU = δQ + δW

気体の準静的変化での仕事:
δW = -p dV

よって:
dU = δQ - p dV
δQ = dU + p dV

熱効率:
η = -W / Q2 = 1 - Q1/Q2

カルノー効率:
ηc = 1 - T1/T2
```

## 10. 口頭説明

```text
熱力学第一法則は、内部エネルギーの変化が、外から入った熱と外からされた仕事の和で表されるというエネルギー保存則です。
気体が準静的に体積変化するとき、外部から気体にされた仕事は δW = -p dV なので、第一法則は dU = δQ - p dV と書けます。
また、熱機関の効率は受け取った熱のうち仕事に変わる割合で、理想的なカルノーサイクルの最大効率は ηc = 1 - T1/T2 です。
```
