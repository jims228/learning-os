理由:

- ガソリンエンジンの例として説明しやすい。
- PV図が比較的有名。
- 熱効率の公式が短い。

## オットーサイクルで書く場合の骨組み

オットーサイクルは、理想的なガソリンエンジンのサイクル。

4つの過程:

| 過程 | 内容 |
|---|---|
| 1 -> 2 | 断熱圧縮 |
| 2 -> 3 | 等積加熱 |
| 3 -> 4 | 断熱膨張 |
| 4 -> 1 | 等積冷却 |

熱効率:

```text
η = 1 - 1/r^(γ-1)
```

ここで、

```text
r = V1 / V2
```

は圧縮比、`γ = Cp/Cv` は比熱比。

## 情報エントロピーの説明メモ

情報エントロピーは、情報の不確かさ・予測しにくさを表す量。

起こりうる結果が多く、どれが起こるか分かりにくいほど、情報エントロピーは大きい。
逆に、結果がほぼ決まっているなら、情報エントロピーは小さい。

式の代表例:

```text
H = -Σ p_i log p_i
```

ここで `p_i` は各結果が起こる確率。

熱力学のエントロピーが「状態の乱雑さ・場合の多さ」と関係するのに対して、
情報エントロピーは「情報の不確かさ・選択肢の多さ」と関係する。
