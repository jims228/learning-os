## 問題文

Lec02スライドに載っている宿題:

1. 熱力学第0法則を調べ、理解した上で、自分の言葉で述べなさい。
2. 熱力学第1, 2, 3法則をそれぞれ記述しなさい。

## 提出先

LMSの `Lec02` 宿題提出欄。

## まず調べる言葉

| 用語 | メモ |
|---|---|
| 熱力学第0法則 | 熱平衡と温度の定義に関係 |
| 熱力学第1法則 | エネルギー保存。内部エネルギー、熱、仕事 |
| 熱力学第2法則 | 熱の自然な向き、熱効率、エントロピー |
| 熱力学第3法則 | 絶対零度に近づくとエントロピーが一定値に近づく |

## 解答の型

### 第0法則

自分の言葉で:

```text
物体Aと物体Bが熱平衡で、物体Bと物体Cも熱平衡なら、
物体Aと物体Cも熱平衡である、という法則。
この法則によって、温度という共通の尺度を定義できる。
```

### 第1法則

```text
熱力学第1法則は、熱を含めたエネルギー保存則である。
系の内部エネルギーの変化は、外から加えられた熱と、
外からされた仕事の和に等しい。
```

授業の記号:

```text
dU = δQ + δW
```

### 第2法則

```text
熱力学第2法則は、自然な熱の移動には向きがあることを表す。
熱は自然には高温物体から低温物体へ移動し、
低温物体から高温物体へ勝手に移動することはない。
```

熱機関で言えば:

```text
受け取った熱をすべて仕事に変えることはできない。
```

### 第3法則

```text
熱力学第3法則は、絶対零度に近づくと、
完全結晶のエントロピーが0に近づく、という法則である。
また、有限回の操作で絶対零度に到達することはできない、
という形でも述べられる。
```

## 提出用の短い解答案

熱力学第0法則は、熱平衡の推移性を表す法則である。
すなわち、AとBが熱平衡であり、BとCも熱平衡であるなら、AとCも熱平衡である。
この法則により、温度を物体に共通する量として定義できる。

熱力学第1法則は、熱を含むエネルギー保存則である。
系の内部エネルギーの変化は、外部から加えられた熱と外部からされた仕事の和に等しい。
式で書くと、授業の記号では `dU = δQ + δW` である。

熱力学第2法則は、自然な熱の移動には向きがあることを表す。
熱は自然には高温側から低温側へ流れ、低温側から高温側へ勝手に流れることはない。
また、熱機関では、受け取った熱をすべて仕事へ変えることはできない。

熱力学第3法則は、絶対零度に近づくと完全結晶のエントロピーが0に近づくという法則である。
また、有限回の操作で絶対零度に到達することはできない、という意味でも理解できる。

## 注意

授業では「自分の言葉で」と書かれているので、丸写しではなく、少し短く言い換える。
