## 最初の重要公式

| 公式 | 意味 |
|---|---|
| dU = δQ + δW | 内部エネルギー変化 = 熱 + 仕事 |
| δW = -p dV | 準静的な体積変化で外部からされた仕事 |
| dU = δQ - p dV | 第一法則に仕事の式を入れた形 |
| δQ = dU + p dV | 熱を内部エネルギー変化と膨張仕事で表す |
| η = -W / Q2 | 熱機関の効率 |
| ηc = 1 - T1/T2 | カルノー効率 |

## よく混乱する点

### QとWは状態量ではない

Uは状態で決まるが、QとWはどう変化したかで変わる。

そのため、

```text
dU
δQ
δW
```

と書き分ける。

### Wの符号

この授業では、`δW` は「外部から気体にされた仕事」。

```text
δW = -p dV
```

なので、

- 膨張: dV > 0 → δW < 0
- 圧縮: dV < 0 → δW > 0

### 温度はKで使う

カルノー効率では、摂氏ではなく絶対温度を使う。

```text
T[K] = 273 + t[℃]
```
