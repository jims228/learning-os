## 得点戦略

この授業は式が多いが、最初から深い理論を全部理解しようとしない。

まずは次の3つを分ける。

| 種類 | 例 |
|---|---|
| 定義 | 内部エネルギー、熱、仕事、エントロピー、自由エネルギー |
| 法則 | 熱力学第一法則、第二法則、エントロピー増大 |
| 計算 | dU、δQ、δW、熱効率、カルノー効率、理想気体 |

初回で最重要:

```text
dU = δQ + δW
δW = -p dV
dU = δQ - p dV
δQ = dU + p dV
η = -W / Q2
ηc = 1 - T1/T2
```
