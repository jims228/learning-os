# Lec13 後半練習問題

作成: 2026-06-09  
元資料: `lectures/13_210721ex_min.pdf`

## 位置づけ

後半範囲の総合演習。  
期末対策では、この問題群を優先する。

## 問題一覧

### 1. 分子の速さの分布

ひとつの分子の速さが `v` から `v + dv` の範囲にある確率を `F(v)dv` とする。

1. `F(v)` を求め、その概略を図示しなさい。
2. `F(v)` はどの `v` で最大になるかを示しなさい。

### 2. 分子の運動エネルギー分布

単原子分子理想気体の分子の運動エネルギーが `ε` から `ε + dε` の間にある確率を `G(ε)dε` とする。

1. `G(ε)` を求め、その概略を図示しなさい。
2. `G(ε)` はどこで最大になるかを示しなさい。

### 3. 速度の2乗平均

質量 `m` の単原子分子からなる理想気体を考える。

気体分子の速度の2乗平均は、ボルツマン定数 `k` と温度 `T` を用いてどのように表されるか。

### 4. ミクロ状態数・状態密度・確率分布

質量 `m` の `N` 個の単原子分子からなる理想気体が体積 `V` をもち、温度 `T` で平衡状態にあるとする。

#### 4.1 エネルギー以下のミクロ状態数

エネルギー `E` 以下のミクロ状態の数 `W(E)` を求めなさい。  
プランク定数を `h` とすること。

ヒント:

- 多次元球の体積公式を使う。

#### 4.2 状態密度

1個の単原子分子について考える。

エネルギーが `E` と `E+dE` の間にあるミクロ状態の数は、単位エネルギー幅の中のミクロ状態の数 `Ω(E)` を用いて `Ω(E)dE` と表すことができる。

`Ω(E)` を求めなさい。  
また、この `Ω(E)` は何と呼ばれるか答えなさい。

#### 4.3 エネルギー確率分布

この気体がエネルギー `E` をもつ確率 `f(E)` について、その確率分布の概形を図示しなさい。

温度が高い時と低い時の2つの場合を比較して示すこと。

ヒント:

- `f(E)` は2つの変数の積算。

### 5. 分配関数

質量 `m` の `N` 個の分子からなる気体が体積 `V` をもち、温度 `T` で平衡状態にあるとする。

#### 5.1 単原子分子理想気体

1. 分配関数を書き表しなさい。スターリングの近似式 `N! ≈ N^N e^(-N)` を適用すること。
2. 上記を用いて内部エネルギーを導出しなさい。また、その結果を用いて定積比熱を求め、さらに比熱比を求めなさい。
3. 上記を用いて、エントロピーとヘルムホルツの自由エネルギーをそれぞれ導出しなさい。
4. 上記を用いて理想気体の状態方程式が成立することを示しなさい。

ヒント:

- 圧力は分配関数でどのように表されるか。

#### 5.2 実在気体

実在気体、つまりファンデルワールス力を考慮した気体の場合を考える。

分配関数が与えられているとして、ファンデルワールスの状態方程式

```text
(p + a/V^2)(V - b) = NkT
```

が成り立つことを示しなさい。

ヒント:

- 圧力は分配関数でどのように表されるか。

### 6. クラウジウス・クラペイロンの式

状態図で気相・液相の共存曲線を表すクラウジウス・クラペイロンの式に関する問題。

1. ギブスの自由エネルギーを用いた平衡条件から、空欄を埋めて式を導出しなさい。添字 `g` と `l` はそれぞれ気相と液相を表す。`s` は各相の単位質量あたりのエントロピー、`v` は各相の単位質量あたりの体積、`p` は圧力、`T` は温度を表す。
2. 単位質量あたりの液体が気体になるときに吸収する熱量、つまり気化熱を `Q` とすれば、式を書き換えられることを示しなさい。
3. 1気圧での水の沸点は100℃である。この時の気化熱を1gあたり500 calとし、`vg = 1 m^3/kg`, `vl = 10^-3 m^3/kg` とする。この時、1気圧上昇すると沸点はどれくらい変わるか計算して答えなさい。
